# Decision Log

## 2026-06-22

- 决定建立独立的前端迭代留档目录：`frontend-design-iterations/`。
- 决定在产品经理方案未到位前，先做项目结构盘点和记录框架，不抢先定最终视觉方向。
- 决定把后续生成图、检索素材和裁切导出统一归档到 `assets/`。

## 2026-06-24

- 决定将 fhl Responses imagegen 作为本项目的前端素材生成能力。
- 决定使用 `gpt-image-2` 同时作为 Responses 外层模型和 image tool 模型。
- 决定把完整安装事项沉淀到 `frontend-design-iterations/frontend-ui-designer-role-card.md`。
- 决定 API key 只保存在本地 `.env`，不写入任何迭代文档。

## 2026-06-24 Images API Correction

- 废弃 fhl Responses API 生图方案。
- 后续 fhl 生图只能使用 Images API：`/v1/images/generations` 或 `/v1/images/edits`。
- `package.json` 使用 `imagegen:images` 作为唯一推荐生图脚本。
- 旧 Responses 入口必须保持禁用，防止再次产生高额 token 计费风险。

## 2026-06-24 TabBar Restructure

- 决定将底部菜单栏调整为「心理咨询 / 心理测评 / 心情日记 / 纸飞机 / 我的」。
- 决定暂时移除底部“心灵社区”入口，但保留相关页面代码，避免后续需要时重复搭建。
- 决定把纸飞机单独提升为主包 tab 页，确保底栏入口可直接打开。
- 决定为纸飞机补一对与现有 tabBar 家族一致的本地图标。
- 决定移除“心情日记”页内原有纸飞机卡片，避免独立模块重复展示。

## 2026-06-24 Daily Checkin Layout

- 决定将“心情日记 / 每日打卡”首页收敛为三个模块：今日打卡、心情日历、心情分析。
- 决定暂时隐藏心灵记事簿入口。
- 决定采用一个大方卡 + 两个小方卡的卡片布局。
- 决定当前先用本地生成 PNG 素材落地，后续 fhl Images API 恢复后可替换同名素材。

## 2026-06-24 Daily Checkin Record Redesign

- 决定将每日打卡记录页从旧的列表选择器结构改为参考图中的卡片式记录界面。
- 决定使用自定义导航栏承载返回、标题、报告入口和更多操作，使页面首屏更接近设计稿。
- 决定将心情选项收敛为 6 个：开心、平静、难过、生气、放松、疲惫。
- 决定将状态选项收敛为 6 个：工作、学习、美食、生病、运动、出游。
- 决定当前先用本地生成和裁切的 PNG 图标版图落地；fhl Images API 恢复后可替换同路径同名素材。

## 2026-06-25 Checkin 24-Dimension Icons

- 按产品经理群聊定版，将每日打卡记录页心情维度升级为 24 项单选。
- 心情区采用默认 6 项折叠展示，展开后显示完整 24 项 6x4 网格。
- 按产品经理群聊定版，将状态维度升级为 24 项多选，并限制至少 1 个、最多 3 个。
- 当前状态区直接展示 24 项 6x4 网格，后续如果页面过长，可再改为默认 12 项 + 展开。
- 心情和状态图标均使用用户提供的高清总图裁切为 `256x256 RGBA PNG`，不再使用上一轮本地绘制的 6 项临时图标。

## 2026-06-25 Checkin Record Detail Polish

- 决定心情区和状态区均直接展示完整 24 项网格，不再使用展开按钮。
- 决定颜色区不展示描述文案，仅在选中色块后居中显示颜色名。
- 决定暂时移除关键词功能，让记录流程回到心情、状态、颜色、文本、照片的主线。
- 决定将天气占位改为 GPS 定位展示；当前前端只展示坐标，后端保存位置字段后续再扩展。

## 2026-06-25 Checkin Location Picker

- 决定定位交互使用微信官方 `wx.chooseLocation` 地图选点，而不是直接展示经纬度。
- 当前前端优先显示中文地点名；位置持久化等待后端扩展字段后再接入。
