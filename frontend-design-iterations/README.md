# Frontend Design Iteration Archive

这个目录用于记录 `AImental_frontend` 的 UI/素材/交互迭代过程，方便和产品经理的 `product-design-iterations/` 对齐回溯。

## 目录说明

- `chat-log.md`：按时间记录每次关键聊天内容与结论。
- `decision-log.md`：记录已经确认的设计决策。
- `backlog.md`：记录待办需求、待确认问题和后续优化项。
- `iterations/`：每一轮实际设计/实现迭代的完整记录。
- `assets/`：素材归档位，后续生成图、找图、裁图、导出图都放这里。

## 工作方式

1. 先等产品经理方案进入 `product-design-iterations/`。
2. 再基于方案拆出前端页面、素材和交互修改。
3. 每次聊天后补 `chat-log.md`。
4. 每次做完一轮设计或实现后补 `iterations/`。
5. 已确认的设计选择同步写入 `decision-log.md`。
