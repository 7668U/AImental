# Iteration 024 - Assessment Test Answer Card

日期：2026-06-29

## 背景

心理测评做题页存在误触滑动后直接进入下一题的问题，用户可能在上一题未作答的情况下继续往后做，最终需要一页一页翻回去查漏。为降低漏答风险，同时提升补答效率，本轮为测评 test 页补充答题卡，并加强前端顺序作答约束。

## 本轮实施

- 为 `AImental_frontend/pkgAssessment/test.js` 增加统一的题目导航守卫，前往后续题目前会检查前面是否存在未作答题。
- 修复 `swiper` 手势前滑误跳题场景：如果发现前面有未作答题，直接强制跳回对应题目并提示用户先作答。
- 为底部进度区域增加可展开/收起的答题卡入口，使用上下方向箭头表达展开状态，不额外增加文字。
- 将答题卡开关调整为贴合进度区域底边的小舌片样式，并改用现有 `AImental_frontend/images/icons/icon-arrow-up.png` / `icon-arrow-down.png` 图标，避免按钮视觉悬浮和风格割裂。
- 根据页面实机效果，进一步将答题卡开关从进度行内部移到整个底部操作卡片的顶部中间，并切换到线上静态资源地址，修复箭头不显示和定位错误的问题。
- 调整答题卡开关的结构挂载位置，使其固定在 `footer-shell` 顶部；收起时贴在底部操作卡上沿，展开时自动上移到答题卡上沿，形成“按钮跟着答题卡伸缩”的视觉效果。
- 新增答题卡网格，展示每道题的已答、未答、当前题状态，支持点击题号快速返回对应题目。
- 提交前新增兜底检查：若仍有未完成题目，自动跳转到首个未作答题并提示。

## 验证

- `node --check AImental_frontend/pkgAssessment/test.js` 通过。
- 已确认答题卡入口位于底部进度条区域下方居中位置。
- 已确认前滑到未作答后续题时，会被前端逻辑强制拦回未完成题。
