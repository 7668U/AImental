# Iteration 004 - Status Dimension Rework

日期：2026-06-24

## 背景

Iteration 003 中对“状态”的设计偏向解释情绪成因，例如没睡够、任务很多、和人争执等。

用户反馈：这里的“状态”不是情绪原因标签，而是类似微信状态的“今天在干什么 / 处于什么生活状态”，例如出差、吃饭、元气满满。

因此，本轮重新定义每日打卡中的“状态”维度。

## 新定义

状态 = 用户今天的生活场景、正在做的事、身体能量或当下气场。

它不负责回答“为什么情绪这样”，而负责回答：

- 我今天在做什么？
- 我今天处在什么生活模式？
- 我今天想用什么状态介绍自己？

## 设计原则

1. 像动态名片：用户看见后会觉得“这就是我今天”。
2. 更适合图标化：每个状态都应该能做成明确 icon。
3. 轻表达：不要太分析化、不要太沉重。
4. 可日常高频使用：覆盖工作、学习、吃饭、出行、休息、娱乐、运动等常见场景。
5. 可与心情组合：例如“焦虑 + 出差中”“开心 + 吃饭中”“疲惫 + 加班中”。

## 推荐 V1 状态分组

共 8 组、48 个状态。前端可以默认展示高频状态，更多状态通过分组展开。

| 状态组 | 选项 | 说明 |
| --- | --- | --- |
| 能量气场 | 元气满满、充电中、低电量、松弛一下、认真模式、摆烂中 | 表达今天整体能量和姿态 |
| 工作学习 | 搬砖中、开会中、加班中、赶进度、学习中、摸鱼中 | 覆盖工作与学习场景 |
| 吃喝生活 | 吃饭中、喝咖啡、做饭中、外卖到、逛超市、家务中 | 覆盖生活琐事和吃喝场景 |
| 出行移动 | 通勤中、出差中、旅行中、回家路上、散步中、等车中 | 覆盖移动状态 |
| 休息恢复 | 睡觉中、补觉中、躺平中、泡澡中、放空中、早睡计划 | 覆盖休息和恢复 |
| 运动户外 | 运动中、健身中、跑步中、遛弯中、晒太阳、户外中 | 覆盖身体活动 |
| 兴趣娱乐 | 听歌中、追剧中、打游戏、看书中、拍照中、刷手机 | 覆盖娱乐和兴趣 |
| 社交陪伴 | 独处中、约会中、聚会中、陪家人、想见你、勿扰模式 | 覆盖社交和陪伴状态 |

## 默认高频 16 个

首页状态选择区建议优先展示：

- 元气满满
- 充电中
- 低电量
- 搬砖中
- 学习中
- 吃饭中
- 喝咖啡
- 通勤中
- 出差中
- 回家路上
- 躺平中
- 睡觉中
- 运动中
- 听歌中
- 独处中
- 勿扰模式

## 选择规则

建议状态支持多选，但限制数量：

- 最少 1 个。
- 最多 3 个。

原因：

- 类似微信状态，本质是表达当前状态，不宜选太多。
- 最多 3 个可以组合出真实生活感，例如“出差中 + 喝咖啡 + 低电量”。
- 比最多 5 个更轻，也更适合前端展示。

## 前端呈现建议

### 记录页

标题建议：

> 今天你处在什么状态？

副标题建议：

> 选几个最像今天的状态。

交互建议：

- 默认展示 16 个高频状态。
- 点击“更多状态”展开 8 个分类。
- 选中的状态固定在顶部形成一行“小状态条”。
- 每个状态使用 icon + 文案，例如咖啡杯、行李箱、床、耳机、月亮等。

### 首页卡片

记录后首页可以显示：

> 今日状态：出差中 · 喝咖啡 · 低电量

配合心情与颜色：

> 焦虑 / 出差中 · 喝咖啡 · 低电量 / 雾灰蓝

## 数据结构建议

每个状态项建议包含：

- `status_id`
- `status_label`
- `status_group`
- `status_type`：activity / energy / travel / rest / social / entertainment
- `icon_name`
- `default_color_hint`

示例：

```json
{
  "status_id": "travel_business_trip",
  "status_label": "出差中",
  "status_group": "出行移动",
  "status_type": "travel",
  "icon_name": "suitcase",
  "default_color_hint": "cool"
}
```

## 与分析的关系

这一版状态不直接表示情绪原因，但仍然有分析价值：

- 哪些生活状态最常和低落一起出现？
- 哪些状态更容易对应高能量？
- 用户在“出差中 / 加班中 / 通勤中”时更容易选择什么颜色？
- 哪些状态是用户的恢复场景，例如听歌、散步、睡觉？

## 替代说明

Iteration 003 中的“状态维度”部分被本轮方案替代。

Iteration 003 的“状态”更适合作为后续可选的“触发因素/原因标签”，不应放在主记录三维度里。

新的三维结构为：

- 心情：我今天感觉如何。
- 状态：我今天在做什么 / 处于什么模式。
- 颜色：今天像什么颜色。

## 下一步

2. 状态多选，最多 3 个。
