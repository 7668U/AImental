# Iteration 006 - Status Label Refinement

日期：2026-06-25

## 本轮目标

优化 24 个状态的命名方式，让它们更像微信状态、更短、更适合在小程序里展示。

## 用户反馈

上一版大量状态带有“中”，例如充电中、搬砖中、通勤中。用户认为这类命名偏啰嗦，状态标签应该更短，例如“充电”即可。

另外，“陪家人”“和朋友在一起”过长，建议改成更短的“聚会”“宅家”。“勿扰模式”改成“勿扰”。“独处”与“宅家”有重叠，需要替换。

## 新命名原则

1. 2-4 个字优先。
2. 尽量不用“中”“模式”等后缀。
3. 标签要像状态贴纸，一眼能扫懂。
4. 避免同组内语义重叠。
5. 保留生活感，不要太正式。

## 推荐 24 个状态

### 能量气场

- 元气满满
- 充电
- 低电量
- 躺平

### 工作学习

- 搬砖
- 开会
- 加班
- 学习

### 出行移动

- 通勤
- 出差
- 旅行
- 回家

### 吃喝作息

- 吃饭
- 喝咖啡
- 睡觉
- 做饭

### 轻娱乐

- 刷手机
- 听歌
- 追剧
- 打游戏

### 生活社交

- 宅家
- 聚会
- 勿扰
- 放空

## 关键替换

| 旧状态 | 新状态 | 原因 |
| --- | --- | --- |
| 充电中 | 充电 | 去掉冗余后缀 |
| 躺平中 | 躺平 | 更像状态标签 |
| 搬砖中 | 搬砖 | 更短、更口语 |
| 回家路上 | 回家 | 更短，仍能表达移动场景 |
| 刷手机中 | 刷手机 | 去掉冗余后缀 |
| 陪家人 | 宅家 | 更短，也能承载家庭/居家场景 |
| 和朋友在一起 | 聚会 | 更短，覆盖朋友社交场景 |
| 勿扰模式 | 勿扰 | 更像微信状态 |
| 独处中 | 放空 | 与宅家区分，表达精神状态而不是地点状态 |

## 默认展示 12 个

建议默认展示：

- 充电
- 低电量
- 躺平
- 搬砖
- 学习
- 通勤
- 出差
- 吃饭
- 喝咖啡
- 宅家
- 勿扰

## 选择规则

保持：

- 至少选 1 个。
- 最多选 3 个。

示例：

- 出差 · 喝咖啡 · 低电量
- 宅家 · 追剧 · 放空
- 搬砖 · 加班 · 勿扰
