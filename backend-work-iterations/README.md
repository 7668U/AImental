# Backend Work Iterations

This folder is Codex's backend work journal for this project.

## Mission

Codex acts as the backend engineer for this mini program. When the product manager provides a product design plan, Codex will update and iterate the backend code to provide correct, reasonable, and frontend-friendly APIs.

## How This Folder Is Used

- `iteration-log.md` tracks each backend iteration at a high level.
- `notes/` stores dated summaries of important conversations, decisions, API changes, risks, and verification results.
- Each implementation round should add or update a dated note so later work can quickly recover context.
