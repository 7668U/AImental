# Audio Assets

Selected CC0 audio assets for the Drink-TI H5 quiz.

- `candidates/glass_005.ogg`: click feedback from Kenney Interface Sounds, original `glass_005.ogg`
- `kenney-pluck-001.ogg`: previous click feedback from Kenney Interface Sounds, original `pluck_001.ogg`
- `first-light-particles-bgm.mp3`: First Light Particles by Yoiyami, from OpenGameArt.org
- `audio-on-icon.png`: enabled BGM icon from user-provided artwork
- `audio-muted-icon.png`: muted BGM icon from user-provided artwork

Kenney Interface Sounds license is included in this folder. First Light Particles is published under CC0:
